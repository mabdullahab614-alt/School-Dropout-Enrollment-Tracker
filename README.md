## 🎯 What It Does

- 🇵🇰 Built for parents, teachers, and community workers across Pakistan
- 🗺️ Turns national out-of-school statistics into **district-level** numbers
- 🏫 Pairs every district's numbers with a **nearby-school directory**
- 🚩 Lets anyone **flag an unenrolled child** for community-worker follow-up
- 🔒 Every figure is sourced — no guesswork, no inflated claims
- 🧱 Not a hypothetical — real data, real numbers, real deployed product

<br/>

---

<br/>

## 📊 The Problem

<div align="center">

| Region | Out-of-school | Rate |
|:--|:--:|:--:|
| 🇵🇰 **National** | **25.1 million** children (age 5–16) | 35% |
| Punjab | 9.7 million | 27% |
| Sindh | 7.4 million | 44% |
| Khyber Pakhtunkhwa | 4.5 million | 34% |
| Balochistan | 3.5 million | 69% |
| Islamabad Capital Territory | 0.09 million | 15% |

</div>

- 🌍 Pakistan has the **world's second-highest** out-of-school child population
- 💸 Public education spending sits at **≈0.8% of GDP** — well below the UNESCO/SDG-4 benchmark of 4–6%
- ⚧️ In Sindh and KP, more girls than boys are out of school

## 🛠️ Tech Stack

<div align="center">

<img src="https://skillicons.dev/icons?i=nextjs,typescript,tailwind,supabase,vercel" alt="Next.js, TypeScript, Tailwind, Supabase, Vercel"/>

</div>

- ⚛️ **Next.js (App Router) + TypeScript** — file-based routing across Home / Explore Data / Flag a Child / About
- 💅 **Tailwind CSS** — utility-first styling, no separate design-system build step
- ⚙️ **Next.js API routes** — handles district stats, school listings, and child-flagging submissions
- 🗄️ **Supabase (Postgres)** — relational fit for province → district → school data
- 🚀 **Vercel** — zero-config deployment, matches Next.js natively
