# Roll Call — School Dropout & Enrollment Tracker

AI Seekho — Assignment 4. A Next.js app that shows verified out-of-school
child statistics for Pakistan by province/district and helps people find
nearby schools.

## Data sources

- UNICEF Pakistan, Education overview (2026)
- Pakistan Bureau of Statistics, HIES 2024–25

School listings are illustrative sample data for this MVP.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000
